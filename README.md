# HR Analytics Project

### Project Overview
Analyzed HR data to find insights about employee salary, hiring trends, and performance.

### Tools & Skills
`Python` `Pandas` `Matplotlib` `Seaborn` `Jupyter Notebook` `Data Analysis`

### Key Insights
1.  **Salary**: IT department has the highest average salary
2.  **Hiring**: Peak hiring happens in Q1 - January and March
3.  **Drivers**: Salary is strongly correlated with Tenure and Performance Rating

### How to Run
1.  Open `HR_Analytics_Project.ipynb` in Google Colab or Jupyter
2.  Run all cells
